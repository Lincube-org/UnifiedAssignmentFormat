# `uaf_payload.csv` 数据规范（UAF v1.0）

## 1. 文件与记录

| 属性 | 要求 |
|------|------|
| 文件名 | `uaf_payload.csv` |
| 编码 | UTF-8，无 BOM |
| 表头 | 必须且只能出现一次，位于第一条记录 |
| 数据记录 | 至少一条；每条表示一项作业 |
| 字段数 | 每条记录恰好四个字段，顺序固定 |

表头必须是以下未加引号的字节内容：

```csv
subject,date,content,tags
```

记录分隔符可使用 CRLF 或 LF，最后一条记录后可省略记录分隔符。读取器也可接受单独的 CR。空记录非法。生成器应统一使用 LF，并在最后一条记录后保留一个 LF，以提高跨实现一致性；这不是合规的必要条件。

字段长度按 Unicode 码点计数。本版不要求 Unicode 规范化，也不得在解析时擅自执行 NFC/NFD 转换、去除字段首尾空白或改变字段内容。

## 2. CSV 编码

CSV 使用 RFC 4180 的字段与引号规则，并应用本文件的固定表头、四列和非空文档约束：

1. 字段以逗号分隔；
2. 含逗号、双引号、CR 或 LF 的字段必须用双引号包裹；
3. 引号字段内的 `"` 必须写成 `""`；
4. 引号字段可包含换行，换行属于字段值而非记录分隔符；
5. 引号必须按 CSV 语法使用，未闭合引号、引号后的非法字符和多余字段均使载荷无效；
6. 空白是字段内容的一部分，不是隐式填充或归一化对象。

只有表头而没有数据记录的文件不是合法 UAF 载荷。

## 3. 字段定义

### 3.1 `subject`

- 类型：字符串；
- 含义：作业科目；
- 约束：非空，最多 200 个 Unicode 码点。

### 3.2 `date`

- 类型：字符串；
- 含义：布置日期或日期时间；
- 允许形式：
  - 日期：`YYYY-MM-DD`；
  - 日期时间：`YYYY-MM-DDTHH:mm:ss`，秒后可带小数部分，末尾可带 `Z` 或 `±HH:mm` 时区偏移。

等价的语法表达式为：

```text
YYYY-MM-DD
YYYY-MM-DDTHH:mm:ss[.fraction][Z|±HH:mm]
```

日期必须是有效的公历日期。时间的小时为 `00` 至 `23`，分钟和秒为 `00` 至 `59`；时区偏移必须有效。`T` 和 `Z` 使用大写。不得使用依赖地区习惯的日期格式，也不得以运行平台能否 `Date.parse` 作为唯一有效性判据。

没有时区偏移的日期时间表示未指定时区的本地时间。读取器不得擅自将其当作 UTC；如业务需要转换，必须由应用另行确定时区。

示例：

```text
2026-05-19
2026-05-19T08:30:00
2026-05-19T08:30:00.125Z
2026-05-19T08:30:00+08:00
```

### 3.3 `content`

- 类型：字符串；
- 含义：作业正文；
- 约束：非空，最多 2000 个 Unicode 码点；
- 换行：可包含 CR、LF 或 CRLF，必须按第 2 节加引号；
- 保真：解析与序列化不得改变正文换行或静默截断内容。

### 3.4 `tags`

- 逻辑类型：有序字符串数组；
- CSV 表示：标签之间使用英文分号 `;`；
- 无标签：使用空字段；
- 标签数量：最多 20 个；
- 单个标签：非空，最多 50 个 Unicode 码点，不得包含 `;`。

非空 `tags` 字段按 `;` 分割后，每一段就是一个标签。空段（例如 `必做;;几何`、以 `;` 开头或结尾）非法，读取器不得通过过滤空段或修剪空白把非法载荷静默转换为另一份数据。

序列化时使用 `tags.join(';')`；解析空字段时得到空数组。标签顺序具有意义，必须保留。

## 4. 逻辑层映射

每个数据记录映射为一项作业，记录顺序即展示与交换顺序：

```typescript
interface UafAssignment {
  subject: string;
  date: string;
  content: string;
  tags: string[];
}

type UafDocument = [UafAssignment, ...UafAssignment[]];
```

解析结果必须保留字段值、记录顺序和标签顺序。除 CSV 语法所要求的引号解码外，不得对字段进行隐式修剪、截断或重排。

## 5. 示例

### 5.1 简单作业

```csv
subject,date,content,tags
数学,2026-05-19,完成课本第45页第1、2题，请拍照上传。,必做;几何
```

### 5.2 多行正文

```csv
subject,date,content,tags
语文,2026-05-19,"背诵《静夜思》
第二段抄写生字",必做
```

### 5.3 无标签

```csv
subject,date,content,tags
英语,2026-05-19,朗读课文 Unit 3,
```

### 5.4 带时区的日期时间

```csv
subject,date,content,tags
科学,2026-05-19T08:30:00+08:00,完成实验记录,必做
```
