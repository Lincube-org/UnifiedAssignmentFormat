# UAF 作业卡片视觉参考 v1.0

> **非规范性参考**：本文描述参考实现的一组默认视觉参数，不定义 UAF 合规条件。纸张、布局、颜色和字体均可替换；UAF 合规要求只由 [uaf-v1.0.md](./uaf-v1.0.md)、[csv-schema.md](./csv-schema.md) 及可选整合包规范定义。

## 1. 页面与卡片流

参考实现采用 A4 纵向页面和双列卡片流：

| 属性 | 参考值 |
|------|--------|
| 页面尺寸 | 595.28 × 841.89 pt |
| 页数 | 一至多页 |
| 页面背景 | `#F8FAFC` |
| 页边距 | 40 pt |
| 列数 | 2 |
| 列间距 | 14 pt |
| 卡片背景 | `#FFFFFF` |
| 卡片边框 | 1 pt，`#E2E8F0` |
| 卡片圆角 | 16 pt |
| 卡片内边距 | 24 pt |
| 卡片高度 | 随内容变化 |

卡片按 CSV 记录顺序从左到右、从上到下排列。PDF 原生绘制使用左下角原点、Y 轴向上；HTML 排版遵循 CSS 坐标系。

## 2. 续卡与分页

参考实现通过续卡和分页保留完整展示内容：

- 一整行卡片无法放入当前页时，从下一页继续；
- 长正文拆成多个带 `（续）` 标识的卡片，后续正文卡不重复标签；
- 标签超过单卡容量时，追加带 `（续）` 标识的标签卡，保持原顺序；
- 不用省略号、裁切或隐藏代替续卡；
- 每页显示总规范规定的固定水印。

不同排版引擎可以采用不同的字符测量和断行位置，因此同一载荷的卡片数和页数可以不同。

### 3.1 科目胶囊

| 属性 | 参考值 |
|------|--------|
| 背景 | `#2563EB` |
| 文字 | `#FFFFFF` |
| 字号 | 14 pt |
| 内边距 | 水平 16 pt，垂直 8 pt |
| 形状 | 胶囊 |

### 3.2 日期胶囊

| 属性 | 参考值 |
|------|--------|
| 背景 | `#F1F5F9` |
| 文字 | `#334155` |
| 字号 | 12 pt |
| 内边距 | 水平 12 pt，垂直 6 pt |

默认展示格式为 `YYYY年M月D日`；也可以选择保留原始 `date` 字符串。展示格式变化不改变 CSV 中的值。

## 4. 正文与标签

正文参考样式：

| 属性 | 参考值 |
|------|--------|
| 字号 | 22 pt |
| 行高 | 1.5 倍字号 |
| 字色 | `#0F172A` |
| 对齐 | 左对齐 |
| 与顶栏间距 | 20 pt |

标签使用独立胶囊形 chip：

| 属性 | 参考值 |
|------|--------|
| 背景 | `#E0E7FF` |
| 字色 | `#3730A3` |
| 字号 | 11 pt |
| 内边距 | 水平 10 pt，垂直 5 pt |
| chip 间距 | 8 pt |
| 与正文间距 | 20 pt |

无标签时不渲染空标签区。内容过长时优先续卡；缩小字号只是可选排版手段，不能导致内容丢失。

## 5. 字体与文件体积

两条参考生成路径采用不同字体策略：

- **原生 PDF 路径**：使用 Noto Sans SC 等覆盖所需字符的字体，并优先只嵌入实际使用的字形子集；缺字时应明确失败或选择覆盖完整的备用字体，避免静默显示为空框或 `?`；
- **HTML 路径**：使用系统中文字体栈。浏览器生成 PDF 时仍可能嵌入全部或部分字体，不能将“HTML 不声明嵌入字体”理解为“输出 PDF 不含字体”。

展示层优先使用矢量文字，不将整页卡片位图化。文件体积受载荷、页数、字体和打印引擎影响，本参考不设统一的 500 KB 验收阈值。

## 6. 水印参考样式

固定水印文本及其合规要求见 [uaf-v1.0.md](./uaf-v1.0.md#43-水印)。参考实现使用以下样式：

| 属性 | 参考值 |
|------|--------|
| 水平位置 | 文本右下角距页面右边缘 40 pt |
| 垂直位置 | 文本右下角距页面下边缘 40 pt |
| 字号 | 10 pt |
| 字色 | `#94A3B8` |
| 透明度 | 50%，或以浅灰色近似 |
| 旋转 | 0° |

水印可叠加在页面空白处或卡片上方，但不能遮挡作业内容。HTML 参考实现使用 `position: fixed`，使 Chromium 打印时每页重复显示水印。

## 7. 可读性建议

- 正文与背景对比度宜达到 4.5:1；
- 水印宜保持较低视觉权重，但不能淡到无法辨认；
- 打印时应保留背景、正文和标签的区分度；
- 普通 PDF 阅读器无需执行脚本即可阅读展示层。
